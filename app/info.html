What it shows

A live heatmap of wildfire probability over Euskadi. Each point is scored by a Random Forest model, and the area in between is interpolated into a continuous map.

Data sources

  • Euskalmet: real observations from the weather stations for the target day (temperature, humidity, wind, rainfall).
  • Open-Meteo: 30-day weather history at each station, plus a coarse grid covering areas more than 15 km from any station.

How the map is built

  • Weather features are computed for each station and grid point, including rolling rainfall, dry-spell length, 14-day evapotranspiration and calendar features.
  • The scaler and Random Forest model turn those features into a fire probability.
  • Inverse distance weighting (IDW) interpolates the probabilities between points onto the heatmap.

Risk tiers

  • Low: probability below 15.7%
  • Medium: 15.7% to 33.2%
  • Extreme: 33.2% and above

Limitations

  • The data covers the previous day's daily aggregates, not the current hour.
  • Interpolation between points is approximate and ignores terrain.
  • The map extends slightly beyond Euskadi's borders because it uses a bounding box.
